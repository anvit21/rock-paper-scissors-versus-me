#  Rock Paper Scissors vs ME (Anvit)

Think you can beat me? Let's find out. (too cheesy?)

A CLI-based Rock Paper Scissors game where you challenge me. 
My move is random, but can you still win?

## How to Run

Make sure you have Python installed, then:

```bash
python rock-paper-scissors-versus.py
```

##  How to Play

- Type `rock`, `paper`, or `scissors` when prompted
- See if you can beat ME
- Play again as many times as you want

## 🛠️ Built With

- Python 3
- `random` module
- Functions
- Conditionals
- User input and basic string methods
